工具: Google Antigravity 指南

发表于 2025-11-24 分类于 工具
Google Antigravity 是由谷歌发布的 AI 驱动集成开发环境（IDE），旨在打造一个"智能体优先"的软件开发平台

📖 工具简介

Google Antigravity 是由谷歌于 2025 年 11 月 18 日发布的 AI 驱动集成开发环境（IDE），旨在打造一个"智能体优先"的软件开发平台。该平台允许开发者将复杂的编码任务委托给自主的 AI 智能体，主要由谷歌的 Gemini 3 Pro 模型提供支持。

Antigravity 基于 Visual Studio Code 构建，支持多种 AI 模型，包括 Anthropic 的 Claude Sonnet 4.5 和开源版本的 OpenAI 模型。

🚀 快速开始

安装方法

macOS（推荐使用 Homebrew）

⚠️ 注意：由于 Antigravity 的下载源由开发者提供（Google CDN），不受 Homebrew 镜像源控制，下载速度可能较慢。建议使用代理工具加速下载。

手动下载安装

  1. 访问 Google Antigravity 官方网站
  2. 下载对应平台的安装包
  3. 按照安装向导完成安装

基本使用

  1. 启动应用：安装完成后，在应用程序中找到 Antigravity 并启动
  2. 登录账号：使用 Google 账号登录（需要支持的地区账号，见下方常见问题）
  3. 创建项目：选择"新建项目"或打开现有项目
  4. 开始使用：在编辑器中编写代码，或通过智能体侧边栏与 AI 智能体交互

📋 功能特性

核心功能

  • ✅ 智能体优先架构：AI 智能体能够自主规划、执行和验证编码任务，减少人工干预，提高开发效率
  • ✅ 多视图界面：
    • 编辑器视图：提供类似于 Visual Studio Code 和 PyCharm 的传统 IDE 界面，集成了智能体侧边栏
    • 管理器视图：作为控制中心，允许开发者协调多个智能体在不同工作区并行工作，实现异步任务执行
  • ✅ 可验证的交付物：智能体生成"工件"（Artifacts），如任务列表、实施计划、截图和浏览器录制等，供开发者验证和参考
  • ✅ 直接系统访问：智能体可直接访问编辑器、终端和集成的浏览器，能够自主执行任务并进行验证

高级特性

  • 🔥 多模型支持：支持 Gemini 3 Pro、Claude Sonnet 4.5 和开源版本的 OpenAI 模型
  • 🔥 多语言支持：支持所有主流编程语言，包括 Python、JavaScript、TypeScript、Java、C++、Go、Rust 等
  • 🔥 并行任务处理：可以协调多个智能体在不同工作区并行工作
  • 🔥 免费使用：在公开预览期间，对所有开发者完全免费，并提供"慷慨的速率限制"

⚠️ 常见问题

问题1：登录无反应或卡顿在"Setting up your account"

解决方法： 开启代理的 TUN 模式（虚拟网络代理）。以 Clash 为例：启动 Clash → General 页面 → 开启 TUN Mode → 点击 install → 重启 Clash → 重启 Antigravity。如仍不行，可尝试切换节点或点击登录成功页面中的 "Click here"。

问题2：地区不支持

解决方法：

  • 切换为支持地区的 Google 账号（常见支持：美国、日本；不支持：中国大陆、香港）
  • 或修改账户关联地区：修改账户地区
