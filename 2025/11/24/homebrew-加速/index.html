工具: Homebrew 加速指南

发表于 2025-11-24 分类于 工具
Homebrew 是什么以及如何在中国大陆加速使用 Homebrew

📖 简介

什么是 Homebrew？

Homebrew 是 macOS（和 Linux）上最流行的包管理器，被称为"macOS 缺失的包管理器"（官网）。

核心特点

  • 简单易用：通过命令行即可安装、更新、卸载软件
  • 开源免费：完全开源，社区驱动
  • 依赖管理：自动处理软件依赖关系
  • 广泛支持：支持大量软件包（formulae）和应用程序（casks），覆盖主流开发工具和应用

Homebrew 组成部分

Homebrew 由以下几个核心组件组成：

组件 说明 链接
brew Homebrew 源代码仓库，包含核心命令和逻辑 GitHub
homebrew-core Homebrew 核心源，包含通过源码编译安装的软件包（formulae） GitHub
homebrew-cask 提供 macOS 应用和大型二进制文件的安装，通过下载预编译的应用包安装 GitHub
homebrew-bottles 预编译二进制软件包，加速软件安装过程（无需从源码编译） 文档

术语说明：

  • formulae：通过源码编译安装的软件包，通常体积较小，安装时间较长
  • casks：预编译的 macOS 应用程序，直接下载安装，通常体积较大但安装快速
  • bottles：预编译的二进制包，用于加速 formulae 的安装，避免每次从源码编译

基本使用

🚀 加速方法

由于网络环境限制，在中国大陆使用 Homebrew 时可能会遇到下载速度慢、连接超时等问题。以下是几种有效的加速方法，按推荐程度排序：

方法一：使用国内镜像源（推荐）

这是最常用且最稳定的加速方法，通过配置环境变量和更新仓库地址来使用国内镜像源。

步骤 1：临时设置镜像源（测试用）

💡 说明：HOMEBREW_API_DOMAIN 用于加速 brew search 命令，该命令会从 formulae.brew.sh/api/formula.jws.json 下载软件包信息。配置此环境变量后，brew search 将使用镜像源加速。

步骤 2：永久配置环境变量

将环境变量添加到 shell 配置文件中，使配置在每次打开终端时自动生效：

环境变量说明：

  • HOMEBREW_BREW_GIT_REMOTE：Homebrew 核心仓库镜像地址
  • HOMEBREW_CORE_GIT_REMOTE：Homebrew Core 仓库镜像地址
  • HOMEBREW_BOTTLE_DOMAIN：预编译二进制包（bottles）镜像地址
  • HOMEBREW_API_DOMAIN：API 镜像地址，用于加速 brew search 命令（Homebrew 4.0+）

作用说明：设置环境变量后，Homebrew 在运行时（如 brew update、brew install、brew search）会优先使用环境变量指定的镜像源。

步骤 3：更新现有安装的仓库地址

💡 重要：如果你已经安装了 Homebrew，除了设置环境变量（步骤 2），还需要更新已存在仓库的 git remote 地址，这样已克隆的仓库也会使用镜像源。

两种方法的区别：

  • 环境变量（步骤 2）：告诉 Homebrew 运行时使用哪个源，优先级高
  • git remote（步骤 3）：直接修改已存在仓库的远程地址，确保已克隆的仓库也指向镜像源

建议：已安装 Homebrew 的用户应该同时执行步骤 2 和步骤 3，以确保完全切换到镜像源。

⚠️ 注意事项

  1. 镜像同步延迟：国内镜像通常存在数小时到一天的同步延迟（具体时间因镜像源而异），某些最新软件包可能暂时不可用
  2. 镜像源选择：根据社区反馈，清华大学和阿里云镜像通常更新相对更及时，但实际效果可能因网络环境而异
  3. 混合使用：可以同时配置镜像源和代理，提高成功率
  4. 定期更新：建议定期执行 brew update 保持软件包列表最新
  5. 故障排查：如果遇到问题，可以尝试切换不同的镜像源
  6. Homebrew 4.0+ API 加速：Homebrew 4.0 版本引入了 JSON API（formula.jws.json），brew search 命令会使用此 API。配置 HOMEBREW_API_DOMAIN 环境变量可以加速 brew search 命令
