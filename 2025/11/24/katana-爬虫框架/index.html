工具: Katana - 下一代爬虫和蜘蛛框架

发表于 2025-11-24 分类于 工具
Katana 是 ProjectDiscovery 开发的下一代爬虫和蜘蛛框架，支持标准和无头模式、JavaScript 解析、自动表单填充等功能
📖 来源： GitHub - projectdiscovery/katana 点击查看原文

📖 简介

Katana 是由 ProjectDiscovery 开发的下一代爬虫和蜘蛛框架，专为快速、可配置的网页爬取而设计。

项目信息

  • GitHub: projectdiscovery/katana
  • 许可证: MIT License
  • 语言: Go

核心特点

  • ✅ 快速且完全可配置：高性能的网页爬取引擎
  • ✅ 标准和无头模式：支持标准 HTTP 请求和无头浏览器模式
  • ✅ JavaScript 解析/爬取：能够解析和执行 JavaScript，发现动态内容
  • ✅ 自定义自动表单填充：自动填充表单字段，发现隐藏端点
  • ✅ 范围控制：精确控制爬取范围，避免越界访问
  • ✅ 多种输出格式：支持 JSON、JSONL 等多种输出格式

📖 基本使用

基础命令

常用参数

参数 说明 示例
-u 目标 URL -u https://example.com
-list 从文件读取 URL 列表 -list urls.txt
-d 最大爬取深度 -d 3
-c 并发数 -c 10
-timeout 超时时间（秒） -timeout 10
-delay 请求延迟（秒） -delay 1
-rate-limit 速率限制（每秒请求数） -rate-limit 150
-fs 范围字段（dn/rdn/fqdn） -fs rdn
-cs 爬取范围（正则） -cs "example.com"
-no-scope 无范围限制 -no-scope
-mr 匹配正则（仅输出匹配） -mr ".*api.*"
-fr 过滤正则（排除匹配） -fr ".*css.*"
-ef 排除扩展名 -ef png,css,js
-em 匹配扩展名 -em php,html,js
-e 排除主机 -e cdn,private-ips
-jsonl JSONL 格式输出 -jsonl
-silent 静默模式（只输出 URL） -silent
-o 输出到文件 -o results.jsonl
-sr 存储 HTTP 请求/响应 -sr
-srd 存储响应目录 -srd ./responses
-hl 启用无头模式 -hl
-aff 自动表单填充 -aff
-fc 表单配置文件 -fc forms.json
-H 自定义请求头 -H "Cookie: session=abc123"

⚠️ 注意事项

  1. 遵守 robots.txt：Katana 默认会遵守网站的 robots.txt 规则
  2. 速率限制：建议设置合理的速率限制（-rate-limit），避免对目标网站造成压力
  3. 范围控制：使用 -fs 或 -cs 选项限制爬取范围，避免越界访问
  4. 无头模式限制：-sr 选项不支持无头模式
  5. 法律合规：确保在合法授权的情况下使用爬虫工具
  6. 参数说明：使用 katana -h 查看完整的参数列表和说明
